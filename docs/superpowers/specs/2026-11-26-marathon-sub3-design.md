# 年度马拉松破三数据与内容草稿

## 首版产品约定

- 候选为统计年份中国大陆实际举办的中国田协 A/B 类全马（42.195 km），男女均计。以参赛届次计人数，同一人在不同届次赛事分别计入。
- 严格榜统计有效净计时小于 `03:00:00` 的完赛者。净时间正好三小时排除，半马、枪声时间、无效成绩和重复参赛记录排除。
- 官方披露的破三人数可引用。计时方式或三小时边界未明时保留原数和出处，待确认后进入严格榜。只接受明确同口径的官方统计或具备完备性证据的官方成绩。
- 仅在候选目录完整、并且所有可能进入前十的已完赛赛事均已核验时，年度文章才称年度前十。平时注明统计截止日，并显示候选目录及已核验赛事范围。

## 发布链路

1. Python 加载年度候选目录，并按届次和来源采集官方成绩或报告。采集日志区分未配置、失败、待核验和核验通过。线上定时任务与年度回填共用入口。
2. 采集事实形成带来源的结构化快照。采用现有赛历的锁与原子替换机制。快照只包含赛事级汇总，逐人记录仅用于计算。
3. RunAgent 两个聊天入口从同一份快照查询，缺少快照或数据时返回明确状态。榜单及排名由程序计算。
4. 公众号从快照生成榜单事实清单、图表与本地 HTML。周期内另增加明星战报、赛历、训练和营养草稿。采编素材仅使用用户有权使用的本地图片和自产图表。微信接入只上传素材和新增草稿，运营人审阅后在微信后台手动群发。

## 素材与检索

赛事事实卡与运动员时间线保留结构化事实及其出处。现有书籍 RAG 继续服务训练问答。赛道描述、赛后采访摘要及可复用的营养资料可按来源、届次和日期进入独立语料集合。私有训练文件仅在本地解析，可公开的统计由运营人明确选择。

## 首次验收

- 无锡与南京 2026 年官方文章公布的破三数归档为口径未明披露。
- 合成官方完整成绩覆盖三小时边界、无效状态、重复记录与缺页。失败采集保留可核验的旧数据或显式报告缺项。
- Chat 与本地草稿对同一快照给出一致的排序、数字、出处和覆盖范围。测试使用合成数据，真实来源验收独立记录。

## 本地稿件的输入约定

- 战报输入为现有已核验领奖台 JSON 与对应赛历，使用赛事届次或公开运动员姓名筛选。成绩、名次、时间线带独立出处。以官方用时除以项目距离得到均配。PB、纪录、分段和采访只在输入提供证据时出现。
- 教学稿输入为 FIT、GPX 或无定位字段的 JSON 区间数据。JSON 每个区间提供正数 `duration_s`、`distance_m` 及可选 `heart_rate`。以区间时间加权心率，等时长分段计算效率因子和 Pa:Hr，以里程分割整公里计算配速。缺心率时显示缺项。事实清单与图表不包含坐标、绝对时间或文件路径。
- 赛历沿用现有快照，按地区、等级和未来 14 至 28 天筛选。未明确的报名截止和赛道信息保留空白。营养稿使用用户已经核对并提供出处的编辑素材。
- 本地干运行只生成 Fact Sheet 与 HTML，必要时出 PNG。微信写入是单独的显式操作，凭据来自环境变量，只允许上传素材及新增草稿。真实微信账户验收独立执行。

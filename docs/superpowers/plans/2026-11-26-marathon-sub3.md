# 年度马拉松破三榜实施计划

**目标** 让 Python 和 RunAgent 通过同一份结构化快照支持可复核的破三统计及本地预览。

**技术栈** Python 标准库、Java 21、Spring AI。

**规格** [年度马拉松破三数据与内容草稿](../specs/2026-11-26-marathon-sub3-design.md)

## 采集与聚合

- [x] `scripts/collect_marathon_sub3.py` 读取年度候选及明确注册的来源。对 2026 锡马和南马提取官方披露，对有可信行数校验的官方净计时成绩 CSV 进行计算。
- [x] `scripts/test_collect_marathon_sub3.py` 验证严格三小时、半马排除、缺行拒绝、官方披露、重复成绩及失败重试保留既有结果。
- [x] 发布 `schema_version=1` JSON，包含年份、发布时间、统计截止日、候选目录覆盖范围和逐届状态。校验后原子替换，`--dry-run` 支持只读演练。

## Java 查询

- [x] `MarathonSub3.java` 读取并校验快照，按人数计算排名并保留可核验链接。支持逐届披露查询和空数据说明。
- [x] 将年度破三类问句接入 `MarathonChat`，将只读结构化查询接入 `MarathonTools`。通过测试确认跑步训练类破三问句继续走原路径。
- [x] 分别执行 Python 回归与 Gradle 测试。使用非虚构来源验收披露解析，与 Java 聊天测试分别记录。

## 草稿接入

- [x] 先让 CLI 以同一快照生成榜单事实清单和本地预览，区分已核验榜单和官方披露。
- [x] 以现有官方成绩验收战报，以合成训练数据验收教学 PNG。加入赛历和营养模板及 Mock 微信草稿箱回归。
- [ ] 验收真实微信账号、更多赛事来源和年度榜单覆盖。

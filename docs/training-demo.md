# 我的训练演示

这组示例使用独立的合成快照，可用于说明 Watson Running 的私有训练查询。网页在 Classic 助手的「我的训练」视图提供近 7 天、近 30 天、自选日期和标准距离 PB。

## 合成快照

| 日期 | 距离 | 移动时长 |
| --- | --- | --- |
| 2026-11-02 | 5.1 km | 25:30 |
| 2026-11-05 | 7.4 km | 49:30 |
| 2026-11-10 | 2 km | 11:00 |

- 查询 2026-11-01 至 11-07 可得到 2 次活动、12.5 km、移动时长 1:15:00、加权平均配速 6:00/km。快照截止日期是 11-10。
- 查询 5 km PB 可得到 11-02 的 5.1 km 活动，平均配速 5:00/km。结果按整次活动估算，包含对应距离附近的活动。
- 查询 11-08 至 11-09 时返回零次活动。无法读取快照时，网页显示数据不可用和请求 ID。

前端调用已鉴权的 RunAgent API，后端用固定参数调用同机 Running MCP Server 并返回统计结果。该链路没有模型请求。通用跑步问答使用独立的 Chat API。[线上站点](https://run.watsonzhu.cn/) · [部署指南](../deploy/README.md)

# RunAgent 公开体验实施计划

**目标** 在现有三个 API 和同一部署中提供免令牌的同期天气、四书知识、真实公开活动统计和复盘。

**架构** RunAgent 收集有界知识和天气证据。访客统计来自 Running MCP 中独立的已发布活动快照。复盘根据访问权限选择报告存储和活动范围。Watson Running 复用现有页面并提供公开访问入口。

**规格** [公开体验设计](../specs/2026-11-20-weather-knowledge-interview-demo-design.md)

- [x] 为聊天请求增加可选城市、当地时间和证据响应。验证旧请求、匿名默认关闭、书摘范围。通过官方 SDK 查询真实 Weather MCP 的上海预报。
- [x] 为 Running MCP 增加独立公开快照范围，并在训练控制器中固定访客查询公开范围。用合成数据运行打包后的两个服务，验证私有统计不受影响、公开快照缺失时失败关闭。
- [x] 在复盘 GET / POST 内按权限区分生成与读取。验证活动白名单、存储隔离、单次生成、匿名额度和旧报告读取。
- [x] 在 Watson Running 中串起匿名问答、公开训练统计和真实活动复盘。用替身 HTTP 响应验证既有令牌路径、桌面和窄屏浏览器交互与请求形状。
- [x] 整合部署配置，验证本地构建、公开快照同步与回退。
- [ ] 在获准发布时，准备与网站当前发布版本一致的活动快照、四书索引和线上 Embedding 服务。启用公开开关并验收实际的浏览器、DeepSeek、RAG 和 MCP 调用链。
